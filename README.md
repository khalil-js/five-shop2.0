# 🛍️ Five Shop

Five Shop is a modern **front-end e-commerce web application** built with **React + Vite**.  
It simulates a real online clothing store with a smooth user experience, interactive shopping features, and a clean responsive UI.

---

## 🚀 Features

- 🧥 Wide collection of clothing items
- 🔎 Product filtering (by category, price, etc.)
- 🛒 Fully functional shopping cart
- 💳 Checkout flow (front-end simulation)
- 🎨 Modern and responsive UI design
- ⚡ Fast performance with Vite
- 📱 Mobile-friendly layout

---

## 🖥️ Tech Stack

- **React**
- **Vite**
- **JavaScript (ES6+)**

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/BenhamadaKhalil/five-shop.git
```

Navigate into the project:

```bash
cd five-shop
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
